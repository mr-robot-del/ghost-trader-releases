# Ghost Trader — Releases

Ghost Trader is a local-first Windows trading co-pilot. It reads the chart with
an AI analyst, then holds that read to account: every idea is logged before the
outcome is known, and resolved against real MetaTrader 5 bars — so the track
record beside each analysis is measured, not remembered.

It runs entirely on your machine, bound to localhost. Your data, your broker
terminal, your API key.

**Download:** https://ghost-trader.onrender.com

Windows installers are published here under [Releases](../../releases). The
latest build is always at
`releases/latest/download/GhostTrader-Setup.exe`.

This repository hosts the distribution artifacts only — no source.
